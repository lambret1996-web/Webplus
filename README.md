# Webplus - 轻量 iOS 浏览器

基于 WKWebView 的轻量级 iOS 浏览器，支持多标签浏览、手势导航、广告拦截、代理加速、下载管理等功能。

## 当前版本：v14.6

## 功能特性

### 1. 多标签浏览
- 支持 4 个标签页同时浏览
- 顶部标签栏快速切换
- 双击标签返回默认主页
- 每个标签独立维护浏览历史

### 2. 手势导航
- **左滑后退**：手指从右往左滑动超过屏幕 50%，网页执行后退
- **右滑前进**：手指从左往右滑动超过屏幕 50%，网页执行前进
- 滑动过程页面跟随手指平移，松手后自动判断是否触发
- 不足 50% 自动回弹，不触发导航

### 3. 下拉刷新
- 网页区域下拉触发刷新
- 触发高度 70pt，避免误触
- 刷新时显示加载进度条

### 4. 地址栏功能
- 输入网址或关键词智能搜索（谷歌搜索兜底）
- 双击地址栏复制当前网页 URL
- 长按地址栏标签管理：修改名称和地址
- 支持 HTTP/HTTPS 自动补全

### 5. 翻译功能
- 一键翻译当前网页为中文
- 支持多种翻译引擎切换
- 翻译按钮双击刷新当前网页

### 6. 图片长按菜单
- 长按网页图片 0.5 秒弹出菜单
- **访问图片**：在当前标签打开图片原图
- **保存照片**：下载图片并保存到系统相册
- 保存成功/失败均有提示

### 7. 广告拦截
- 内置广告/追踪域名黑名单
- 支持自定义添加/删除/编辑黑名单
- 支持完整域名/路径拦截（如 `xxx.com/ads/banner.gif`）
- 一键拦截当前网站所有图片（全局图片拦截开关）
- 支持导入圈 X 规则格式
- 扩充版广告拦截黑名单，覆盖主流广告网络

### 8. 网页内文字搜索
- 屏幕底部中央双击唤起搜索栏
- 输入关键词自动高亮所有匹配文字
- 上/下箭头快速跳转匹配项
- 搜索栏跟随键盘，美观简洁
- 未点完成前不可关闭窗口

### 9. 下载管理
- 点击下载链接自动识别并下载
- 下载进度实时显示
- 下载管理面板查看所有任务
- 支持暂停/继续/取消下载
- 文件保存到 App 的 Downloads 文件夹
- 一键在文件 App 中打开下载目录
- 文件共享权限开启，可在「文件」App 中查看

### 10. 缓存管理
- 四级缓存体系：内存缓存 → 磁盘缓存 → 网络缓存 → 离线缓存
- 网页缓存有效期 24 小时，过期自动清理
- 图片/视频/静态资源分类缓存
- 一键清空当前站点缓存
- 一键清空全部缓存
- DNS 域名预解析，加速访问
- Pre-Connect TCP 预连接

### 11. UA 切换
- 内置多种 User-Agent 预设：
  - iPhone Safari
  - iPad Safari
  - Chrome iOS
  - Firefox iOS
  - 桌面版 Safari (Mac)
  - Chrome (Windows)
  - Edge (Windows)
  - 自定义 UA
- 切换后自动刷新生效

### 12. 高级代理 (AppProxy)
- 基于 Network Extension 的应用代理
- 支持直连模式（广告拦截 + 请求头修改）
- 支持 VLESS-WS 协议代理
- 节点管理：添加、删除、切换
- 订阅管理：支持 vless://、vmess://、trojan:// 链接
- 支持 Base64 编码的订阅链接
- 自动去重节点
- 排除域名设置

### 13. 右边缘功能菜单
- 从屏幕右边缘下滑唤出功能菜单
- 菜单宽度 50% 屏幕宽度
- 跟随手指滑动，超过 40% 展开，不足自动弹回
- 点击菜单外任意区域自动收起
- 弹出动画 0.6 秒，平缓流畅
- 功能项支持拖拽排序（三横线手柄）

### 14. 功能菜单包含
- 增加书签
- 书签列表（支持管理、删除、修改）
- 历史记录（Safari 风格）
- 下载管理
- 全局图片广告拦截开关
- UA 切换
- 广告拦截自定义黑名单管理
- 清空当前站点缓存
- 一键清空缓存
- 设置

### 15. 书签管理
- 长按 GitHub 标签：收藏当前页为书签
- 长按 CF 标签：打开书签列表
- 书签列表支持删除和修改
- 书签数据持久化存储

### 16. 快捷手势
- 双击屏幕右下角：直达网页顶部
- 双击屏幕左下角：直达网页底部
- 双击翻译按钮：刷新当前网页
- 屏幕底部中央双击：网页内文字搜索

### 17. 性能优化
- 禁止网页媒体自动播放
- 后台动画节流
- 第三方追踪脚本拦截（提速 30%-60%）
- 精细化分类型智能缓存
- WKWebView 进程池复用

### 18. 权限支持
- 相册读写权限
- 相机权限
- 麦克风权限
- 位置权限
- 通知权限
- 所有浏览器相关权限已开启

### 19. 其他特性
- 网页强制缩放（无视网站禁止缩放设置）
- target="_blank" 链接自动在当前页打开
- 加载进度条显示
- 深色/浅色模式自动适配
- 支持横屏浏览

## 技术栈
- 语言：Swift
- 最低系统：iOS 15.0
- 核心：WKWebView
- 网络：URLSession + NetworkExtension
- 构建：Xcode 15.4 / GitHub Actions

## 构建方式
### 云端构建（推荐）
1. 推送代码到 GitHub 仓库
2. GitHub Actions 自动触发构建
3. 构建完成后在 Actions 页面下载 IPA

### 本地构建
```bash
cd Webplus
xcodebuild -project WebViewBrowser.xcodeproj \
  -scheme WebViewBrowser \
  -configuration Release \
  -derivedDataPath build
```

- 不上架 App Store
- AppProxy 功能需要付费开发者账号的 NetworkExtension 权限
